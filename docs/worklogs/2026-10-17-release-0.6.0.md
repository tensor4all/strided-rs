# 2026-10-17: strided 0.6.0 (allocation-free API)

All six crates are released together at **0.6.0**: `strided-traits`, `strided-view`, `strided-perm`, `strided-basic`, `strided-kernel` and `strided-fused`. Versions are unified on the workspace again. The 0.5.x per-crate patch versions (`view 0.5.1`, `basic 0.5.4`, `fused 0.5.2`) were only needed while the providers pinned exact 0.5 versions.

Content: #316, which implements the #306 contract (no library-owned per-call heap allocation at rank ≤ `INLINE_RANK = 8` with ≤ 5 streams, and a graceful spill above), and #317 (`UpdatePlan` does not read the destination when beta is zero, and gains `execute_uninit`). #316's PR description has the per-unit table and the evidence.

## Breaking changes

- `StridedView::new_owned` / `new_owned_unchecked` are removed. `new` copies the metadata inline, and the view's lifetime is the data borrow only.
- `StridedView`, `StridedViewMut` and `StridedArray` are 184 B (were 80 B). Metadata is `tinyvec` inline storage with a heap spill above `INLINE_RANK`.
- `copy_into`, `copy_into_par` and `copy_into_col_major*` require `T: 'static`, because the f32/f64 fast path is now gated on `TypeId` (#289).
- `FusedPlan` and `FusedInst` fields are inline collections. Use `FusedPlan::new` / `FusedInst::new`.
- `BilateralFusionPlan` fields are inline.
- Fused floating `maximum`/`minimum`/`clamp` propagate NaN (#315).
- `UpdatePlan` / `ErasedUpdatePlan` bounds gain `Zero + One + PartialEq`. When beta is zero, the destination is not read.
- The `smallvec` dependency is gone. Inline metadata uses `tinyvec` (#312).

## Publish order

`strided-traits`, then `strided-view`, `strided-perm`, `strided-basic`, `strided-kernel`, and finally `strided-fused`.

## Downstream

- cpueinsum 0.3 (tensor4all/cpueinsum-rs#23) and tlinalg 0.3 (tensor4all/tlinalg-rs#57, #58).
